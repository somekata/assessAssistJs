# 抄録査読システム

以前作成した査読支援ツールを大幅に改善し、**PDF直接読み込みに対応**しました。演題ごとの評価・コメント記録から事務局による集計・CSVエクスポートまで、査読業務の全工程をブラウザ完結で行えます。

---

## ファイル構成

```
📁 抄録査読システム
├── index.html               ← エントリーページ（操作説明・各ツールへのリンク）
├── abstract_review.html     ← 査読ツール（評価者向け）
├── abstract_aggregate.html  ← 集計ツール（事務局向け）
└── README.md                ← このファイル
```

3つのHTMLファイルは**同じフォルダに置いてください**。`index.html` をブラウザで開くと操作説明とリンクが表示されます。

---

## 査読ツール（abstract_review.html）

### 対象
評価者（査読者）

### 主な機能

- **PDF読み込み**：抄録PDFをブラウザで直接読み込み、演題番号・タイトル・抄録本文を自動抽出
- **前へ・次へナビゲーション**：演題を順番に移動しながら評価
- **5段階評価**：★1〜5でスコアを付与（同じ星を再クリックでリセット）
- **ステータス管理**：未着手 / 途中 / 確定 の3段階。確定後は全入力をロック、「未確定に戻す」で再編集可
- **区分設定**：基礎・臨床・未分類を個別または一括で設定
- **コメント入力**：自由記述＋定型文19件プリセット（追加・編集・削除可）
- **採点状況の把握**：ステータスバーに★別件数・確定数を常時表示
- **一覧タブ**：全演題の絞り込み・ソート、チェックによる一括区分設定・一括確定
- **評価者名登録**：設定タブで氏名を登録。エクスポートJSONのファイル名に反映
- **データ保存**：localStorageに自動保存。JSONエクスポート・インポートで持ち運び可

### キーボードショートカット

| キー | 操作 |
|------|------|
| `←` / `→` | 前の演題 / 次の演題 |
| `1` 〜 `5` | 評価を★1〜★5に設定 |
| `Enter` | 評価を確定 |
| `Backspace` | 未確定に戻す |
| `B` | 区分：基礎 |
| `C` | 区分：臨床 |

※コメント入力欄・検索欄にフォーカス中はショートカット無効

### 対応PDFフォーマット

```
1ページ1演題の形式に対応

1行目：演題番号
2行目：演題タイトル
3行目以降：抄録本文
```

## 集計ツール（abstract_aggregate.html）

### 対象
事務局

### 主な機能

- **複数JSON一括読み込み**：評価者全員分のJSONをまとめてドロップ
- **確定済みのみ集計**：ステータスが「確定」の評価のみを対象
- **区分別順位付け**：基礎・臨床それぞれ独立して順位を算出（同点は同順位）
- **平均点算出**：演題ごとに評価者間の平均を計算
- **コメントモーダル**：評価者ごとのコメントを一覧表示
- **統計タブ**：全体サマリー・スコア分布・評価者別統計
- **CSVエクスポート**：集計結果を1クリックで出力

### CSVの列構成

```
順位（区分別）, 演題番号, タイトル, 区分, 平均点, 評価者数,
[評価者1_スコア, 評価者1_コメント, 評価者2_スコア, 評価者2_コメント, ...]
```

## 操作の流れ

```
【評価者】
  1. abstract_review.html を開く
  2. 設定タブで評価者名を入力
  3. PDFを読み込む
  4. 演題ごとに区分・スコア・コメントを入力して「確定」
  5. 設定タブ → JSONエクスポートして事務局に提出

【事務局】
  6. abstract_aggregate.html を開く
  7. 評価者全員分のJSONを一括読み込み
  8. 「集計を実行」で平均点・順位を算出
  9. 集計結果タブで確認、CSVエクスポート
```

## 注意事項

- localStorageはブラウザ・デバイスをまたいで引き継がれません。**JSONエクスポートを定期的に行ってください**。
- ブラウザのキャッシュを削除するとlocalStorageのデータも失われます。
- PDFのテキスト抽出精度はPDFの作成方法に依存します。スキャン画像のPDFには対応していません。
- 集計ツールは同一評価者のJSONを複数読み込んだ場合、**後から読み込んだデータで上書き**されます。
